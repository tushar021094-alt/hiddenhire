# HiddenHire

AI-powered job discovery platform for finding relevant remote and international opportunities.

## V1 Goal

Upload a resume and define job preferences. HiddenHire ranks relevant jobs using transparent matching criteria and highlights remote/India eligibility, compensation, and why a candidate matches.

## V1 Scope

- Resume/profile input
- Target role, salary, location, remote and industry preferences
- Job discovery data layer
- India-eligibility detection
- Salary extraction and USD normalization
- Explainable match scoring
- Direct application links
- Saved/application status tracking
- OpenAI-powered resume/job matching

## Product principle

HiddenHire is not another generic AI chatbot. Its value comes from job discovery, structured data, filtering, ranking, and workflow automation.

## Planned stack

- Next.js + TypeScript
- Tailwind CSS
- OpenAI API
- Supabase-ready persistence
- Vercel deployment
